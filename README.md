# PROJECT CHRONO-7 // AEGIS QUANTUM FIGHTER
### NASA Mission Return & Crew Telemetry // 3D Cinematic Scroll Experience

An ultra-premium, 60+ FPS interactive 3D web experience built with native WebGL, procedural planets (Earth, Mars, Moon), a live spacecraft Crew Manifest UI, and destination landing touchdown at **NASA Kennedy Space Center**.

---

## 🌟 What's New

1. **Spacecraft Crew Manifest UI**
   - Live HUD widget displaying the 5 active astronauts:
     - **👨‍🚀 Dhanesh** — Mission Commander // Flight Deck & Master Telemetry
     - **👩‍🚀 Gayathri** — Chief Navigator // Orbital Mechanics & Earth Descent Vector
     - **👩‍🚀 Girinanda** — Systems Engineer // Quantum Singularity & Power Grid
     - **👩‍🚀 Devika** — Science Specialist // Atmospheric Physics & Life Support
     - **👨‍🚀 Sravan** — Propulsion Lead // Vector Thrusters & NASA Touchdown Burn
   - Animated green biometric heart rate indicators (`♥ 65-74 BPM`), neural link status, and interactive sound feedback.
   - Convenient `[👥 CREW (5)]` button in the top HUD to expand or collapse the crew panel at any time.

2. **NASA Destination & Touchdown (Phase 01 - 05)**
   - The entire flight path now charts the journey from deep space back home to Earth:
     - **Phase 01: Deep Space Departure**: Crew initiates Earth return burn with Zero-Point reactor.
     - **Phase 02: Mars Gravitational Slingshot**: Hypersonic assist past the Red Planet.
     - **Phase 03: Lunar Bypass & Earth Sighting**: Sweeping past the Moon with Earth in the cockpit crosshairs. Communications locked with NASA Houston Mission Control.
     - **Phase 04: Atmospheric Re-entry Burn**: Hypersonic ionization shockwave over North American airspace.
     - **Phase 05: NASA Kennedy Space Center (Florida)**: Main gear touchdown on the NASA Shuttle Landing Facility Runway 15/33. "WELCOME HOME CREW: DHANESH, GAYATHRI, GIRINANDA, DEVIKA, SRAVAN".

3. **Smooth Animated Planets (Near-Zero PC Load)**
   - **Mars**: Rotating red-ochre planet with polar ice caps passed during Phase 02.
   - **The Moon**: Rotating lunar sphere with crater maria passed in Phase 03.
   - **Earth**: Majestic blue oceans, green continents, swirling white clouds, and glowing cyan atmosphere rim light approached during Phase 04-05.
   - **NASA Runway Beacons**: Glowing runway lights and landing grid markers guiding the final touchdown in Phase 05.
   - Built with ultra-efficient procedural geometry (~280 vertices per planet) using existing WebGL draw calls for zero performance impact.

4. **Smoother Easing & Animation**
   - Frame-rate independent exponential interpolation (`1.0 - Math.exp(-8.5 * dt)`) eliminating micro-stutters.
   - Smooth mouse parallax and steering damping.
   - Bidirectional sync between native page scroll, the bottom video timeline scrubber, and autonomous video playback (`[▶ PLAY REEL]`).
